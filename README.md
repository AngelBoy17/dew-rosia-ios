# Роса (Dew)

Маленькое iOS-приложение в стиле **liquid glass**: часы, дыхание 4·4·4 и настроение дня.

- Минимальная iOS: **16.0**
- Bundle ID: `app.liquid.dew`
- Название на домашнем экране: **Роса**
- Только iPhone, портрет

## Почему здесь нет готового IPA

Настоящий `.ipa` для iPhone — это ARM64 Mach-O и UIKit/SwiftUI, собранные **Xcode + iOS SDK**. Это окружение — Linux, без Xcode. Собрать рабочий IPA отсюда нельзя: «пустой» zip без бинарника Scarlet не установит.

Исходники готовы. IPA получается на Mac за одну команду.

## Сборка IPA на Mac (для Scarlet)

1. Установи [Xcode](https://developer.apple.com/xcode/) и один раз открой его (лицензия + iOS SDK).
2. В терминале:

```bash
cd Dew
bash Scripts/build-ipa.sh
```

Файл появится здесь: `dist/Dew.ipa`.

Скрипт собирает **unsigned** IPA (`CODE_SIGNING_ALLOWED=NO`). Scarlet подписывает его своим сертификатом при установке.

Либо открой `Dew.xcodeproj` в Xcode, выбери любой iPhone SDK, Product → Build. Для IPA всё равно удобнее скрипт.

## Установка через Scarlet

1. Перекинь `Dew.ipa` на iPhone (файлы, AirDrop, Discord, браузер).
2. Открой Scarlet → импортируй IPA.
3. Установи и доверь сертификату Scarlet в Настройки → Основные → VPN и управление устройством.

Если iOS ниже 16, установка не запустится — подними Deployment Target или обнови систему.

## Что внутри

- **Роса** — живые стеклянные карточки, время и «капля дня»
- **Дыхание** — цикл вдох / пауза / выдох по 4 секунды
- **Настрой** — настроение сохраняется до следующего дня
